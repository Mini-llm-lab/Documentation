# Mini-LLM

Small assistants (~40M and ~150M parameters on the 32k tokenizer lineage, ~34M and
~70M on the earlier 16k lineage) trained **end-to-end** with PyTorch — custom BPE
tokenizer, transformer decoder architecture, no pretrained backbone. The repository covers the
whole chain:
tokenizer, data, architecture, pretraining, supervised fine-tuning into an assistant,
chat, and export.

Training runs on NVIDIA GPUs (CUDA). Source repository:
[github.com/Mini-llm-lab/Mini-LLM](https://github.com/Mini-llm-lab/Mini-LLM).

> Training scale translates directly into output quality: base val loss drops from
> 3.618 (34M, ~0.2B tokens) to 3.030 (70M, ~1.4B tokens) and to 2.941 (150M, ~4.5B
> tokens) — larger models are markedly more fluent and better formatted. Conformance
> and factual accuracy are tracked continuously with
> [Mini-Eval](https://github.com/Mini-llm-lab/Mini-Eval).

## Quickstart

Requires [uv](https://docs.astral.sh/uv/) and Python 3.11+.

```
git clone https://github.com/Mini-llm-lab/Mini-LLM
cd Mini-LLM
uv sync

uv run prep          # tokenizer + data
uv run pretrain 300  # short smoke run
uv run sft 1
uv run chat
```

To speed up Hugging Face downloads, create a free token and export it before running
`prep` or `sft`: `export HF_TOKEN=...`.

## Project layout

```
Mini-LLM/
├── pyproject.toml
├── data/                  train.bin, val.bin, meta.json (tokens, generated by prep)
├── models/                one folder per tokenizer lineage
├── models/32k/              tok.json shared by the 40M (legacy) checkpoints
├── models/32k/40M/          40M checkpoints and milestones
├── models/32k/150M/         legacy 150M checkpoints (classic tokenizer, ctx 512)
├── models/digit32k/         1.1 tok.json (digit-split) + 1.1 checkpoints
├── models/digit32k/150M/    1.1 150M checkpoints and milestones
└── src/
    └── mini_llm/
        ├── config.py      model configuration, paths, device selection
        ├── model.py       architecture and text generation
        ├── prompt.py      conversation format shared by sft and chat
        ├── identity.py    identity, small-talk and arithmetic examples for sft
        ├── system_prompts.py  default system prompt, obedience variations, uncertainty
        ├── math_data.py   synthetic arithmetic and mini-skills for the 1.1 SFT
        ├── prep.py        tokenizer and data preparation
        ├── pretrain.py    pretraining and distillation
        ├── teacher.py     download and convert the legacy 150M base for distillation
        ├── sft.py         fine-tuning into an assistant
        ├── chat.py        chat interface
        ├── checkpoints.py saving, loading and selecting checkpoints
        ├── configuration_mini_llm.py  HF config (deploys as config.json)
        ├── modeling_mini_llm.py       HF model, same math as model.py
        └── export.py      .pt -> HF directory (config + safetensors + tokenizer)
```
