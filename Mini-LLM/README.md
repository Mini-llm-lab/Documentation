# Mini-LLM

Small assistants (~34M and ~70M parameters, a 150M preset exists) trained **entirely
from scratch** with PyTorch: no pretrained weights, no existing model. The repository
covers the whole chain: tokenizer, data, architecture, pretraining, supervised
fine-tuning into an assistant, chat, and export.

Training runs on NVIDIA GPUs (CUDA). Source repository:
[github.com/GautierPicon/mini-llm](https://github.com/GautierPicon/mini-llm).

> With 34M parameters and ~100M training tokens, the assistant writes coherent
> sentences in the right format, but it often gets facts wrong. The 70M model trained
> on ~1.44B tokens (cloud GPU) lowers base val loss from 3.618 to 3.030: answers are
> more fluent and better formatted, but factual errors and hallucinations remain.

## Quickstart

Requires [uv](https://docs.astral.sh/uv/) and Python 3.11+.

```
git clone https://github.com/GautierPicon/mini-llm
cd mini-llm
uv sync

uv run prep          # tokenizer + data
uv run pretrain 300  # short smoke run
uv run sft 1
uv run chat
```

To speed up Hugging Face downloads, create a free token and export it before running
`prep` or `sft`: `export HF_TOKEN=...`.

## Project layout

```
mini-llm/
├── pyproject.toml
├── data/                  train.bin, val.bin, meta.json (tokens, generated by prep)
├── models/                tok.json (current lineage) + checkpoints (.pt)
├── models/16k/            tok.json + 34M/70M checkpoints (previous lineage)
└── src/
    └── mini_llm/
        ├── config.py      model configuration, paths, device selection
        ├── model.py       architecture and text generation
        ├── prompt.py      conversation format shared by sft and chat
        ├── identity.py    identity, small-talk and arithmetic examples for sft
        ├── prep.py        tokenizer and data preparation
        ├── pretrain.py    pretraining
        ├── sft.py         fine-tuning into an assistant
        ├── chat.py        chat interface
        ├── checkpoints.py saving, loading and selecting checkpoints
        ├── configuration_mini_llm.py  HF config (deploys as config.json)
        ├── modeling_mini_llm.py       HF model, same math as model.py
        └── export.py      .pt -> HF directory (config + safetensors + tokenizer)
```
